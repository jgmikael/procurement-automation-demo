🔗 EBWV Vocabulary Mappings

Power of Attorney uses EBWV for principal, attorney, and company identification.

EBWV Attributes:
ebwv:LegalRepresentative → Principal (grantor)
ebwv:Person → Attorney (agent)
ebwv:Company → Represented company
ebwv:legalIdentifier → EUID
ebwv:Address → Physical addresses

PoA-Specific Extensions:
poa:scope → Granted powers
poa:substitution → Delegation rules
poa:validityPeriod → Time constraints
poa:applicableLaw → Jurisdiction

🏗️ Procurement Use Cases

Authority Verification in Procurement:

  • Tender Submission: Verify attorney has authority to submit on company's behalf
  • Contract Signing: Validate signing authority for awarded contracts
  • Cross-Border M&A: Special powers for mergers, conversions, divisions
  • Audit Trail: Link actions to verified authorization chain
  • Substitution Control: Track if attorney delegates to third parties

Validation Logic:

IF poa.validityPeriod.validFrom <= action.date AND
   poa.validityPeriod.validUntil >= action.date AND
   poa.scopeOfRepresentation.powers.includes(action.type)
THEN attorney.authorized = true
