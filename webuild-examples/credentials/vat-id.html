🔗 EBWV Vocabulary Mappings

VAT ID attestation uses EBWV for economic operator identification.

Core EBWV Attributes:
ebwv:EconomicOperator → Economic operator entity
ebwv:legalName → Legal person name
ebwv:legalIdentifier → EUID structure
ebwv:registeredAddress → Address
ebwv:activity → NACE classification

VAT-Specific Extensions:
vat:vatId → VAT identification number
vat:validityPeriod → Registration period
vat:euCrossBorder → EU transaction eligibility
vat:administrativeUnit → Taxable entity

🏗️ Procurement Use Cases

VAT Verification in Public Procurement:

  • Eligibility Check: Valid VAT registration is mandatory
  • No VIES Query Needed: Credential contains verified VAT status
  • EU Cross-Border: Verify eligibility for EU-wide contracts
  • Invoice Processing: Validate VAT ID on invoices automatically
  • Tax Compliance: Proof of tax registration for payment

Automated Validation:

IF vat.validityPeriod.endDate == null OR
   vat.validityPeriod.endDate > today() THEN
   supplier.taxCompliant = true
END IF
