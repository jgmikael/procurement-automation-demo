🔐 Selective Disclosure Architecture

PD A1 uses 16 SD Element Groups for privacy-preserving disclosure. Unlike field-level SD, entire logical blocks are disclosed together.

SD Element Groups:

SD-1: PIN SD-2: Gender SD-3: Names SD-4: Date of Birth SD-5: Nationalities SD-6: Place of Birth SD-7: Residence Address SD-8: Stay Address SD-9: Employer Details SD-10: Employer Address SD-11: Place of Work (Company) SD-12: Place of Work (Address) SD-13: Status Confirmation SD-14: Document ID SD-15: Institution Details SD-16: Institution Address

🔒 Privacy Design Principles

  • Group-level disclosure: Cannot disclose "street" without "town" - entire address block disclosed together
  • GDPR compliance: Relying Parties can only request element groups they're authorized to receive
  • Non-SD core: Member state legislation (jurisdiction, dates) always disclosed - core legal requirement
  • Modular presentation: Different RPs request different group combinations based on use case
