🏦 What is a Legal Entity Identifier?
The Legal Entity Identifier (LEI) is a 20-character alphanumeric code (ISO 17442) that uniquely identifies legal entities participating in financial transactions globally.

Purpose:
  • Improve transparency in global financial markets
  • Reduce counterparty risk in cross-border transactions
  • Enable standardized identification across jurisdictions
  • Support regulatory reporting requirements

Established by the G20 following the 2008 financial crisis to create a global "social security number" for businesses engaged in financial transactions.
📋 LEI Attestation Use Cases
This LEI attestation enables:
  • Financial Transactions: Verify counterparty identity in derivatives, securities, and lending
  • Regulatory Reporting: MiFID II, EMIR, Dodd-Frank compliance
  • KYC/AML: Streamlined due diligence for financial institutions
  • Supply Chain Finance: Verify supplier identity in trade finance
  • Corporate Actions: Shareholder identification and dividend payments
  • Cross-Border Commerce: Global entity authentication beyond finance
📊 LEI Status Values
Possible LEI status values:
  • ISSUED: ✅ Active and valid (current example)
  • PENDING_VALIDATION: ⏳ Registration in progress
  • LAPSED: ⚠️ Expired, renewal required
  • RETIRED: 🔚 Entity no longer exists
  • DUPLICATE: ⛔ Duplicate registration detected
  • ANNULLED: ❌ Registration cancelled (invalid data)
  • CANCELLED: 🚫 Voluntarily cancelled by entity
  • TRANSFERRED: 🔄 Moved to another LOU

🔒 LOU as Authentic Source
The LEI attestation is issued by an accredited Local Operating Unit (LOU), not by GLEIF directly. LOUs are the authentic sources within the Global LEI System:
  • Validate entity data against local business registers
  • Accountable for data correctness (up to loss of accreditation)
  • Issue and manage LEI registrations and renewals
  • Any accredited LOU may issue attestations based on authoritative LEI data

GLEIF (Global Legal Entity Identifier Foundation) acts as an aggregator, publishing the Global LEI Index, but bears no legal responsibility for data accuracy.

🔒 Selective Disclosure Attributes
NOT selectively disclosable (always visible):
  • lei - Legal Entity Identifier code
  • lei_status - Registration status
  • lei_renewal_date - Next renewal date

All three attributes are mandatory and cannot be selectively disclosed. This attestation provides minimal, essential LEI information only.
⚠️ Verification Requirements
Relying parties MUST:
  • Verify issuer signature using LOU trust anchor from GLEIF Trusted List
  • Check attestation expiration date
  • Validate LEI format: 20-character alphanumeric (ISO 17442)
  • Confirm lei_status is "ISSUED" for active entities
  • Verify lei_renewal_date is in the future
  • Request and verify holder's PID to confirm entity identity
  • Cross-reference with GLEIF Global LEI Index if high assurance required

Note: GLEIF Global LEI Index is synchronized periodically and may disseminate stale data. LOUs are the authentic sources.

🏛️ Global LEI System
System Architecture
GLEIF (Global Legal Entity Identifier Foundation):
  • Oversees the Global LEI System
  • Accredits Local Operating Units (LOUs)
  • Publishes the Global LEI Index (aggregated data)
  • Performs data quality checks
  • ⚠️ Bears no legal responsibility for data accuracy

LOUs (Local Operating Units):
  • ✅ Authentic sources for LEI data
  • Issue and manage LEI registrations
  • Validate entity data against local registers
  • Accountable for data correctness (up to loss of accreditation)
  • Can issue attestations based on authoritative data

🔍 LEI Code Structure (ISO 17442)
The LEI code 529900HNOAA1KXQJUQ27 consists of:
  • Characters 1-4: LOU identifier prefix (5299)
  • Characters 5-6: Reserved (00)
  • Characters 7-18: Entity-specific identifier (HNOAA1KXQJUQ)
  • Characters 19-20: Check digits (27) - ISO 17442 validation

The code is globally unique and never reassigned to another entity.
