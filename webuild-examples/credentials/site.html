🔒 Selective Disclosure Attributes
The following attributes MAY be selectively disclosable:
  • Additional site identifiers (GLN, BPNS, DUNS)
  • Additional addresses (logistics center, alternate entrances)
  • Additional economic operator identifiers (LEI, DUNS, BPNL, GLN)

The following attributes are MANDATORY and not selectively disclosable:
  • Site name
  • Site main ID (UUID)
  • Main address (all components)
  • Economic operator primary identifier (EUID preferred)
⚠️ Verification Requirements
Relying parties SHOULD:
  • Verify issuer signature using economic operator's trust anchor
  • Check attestation expiration date
  • Validate site UUID format (RFC 4122)
  • Verify economic operator identification (EUCC, LEI, or other attestations)
  • For KYS/KYC: Cross-reference with business register data
  • Validate address format according to Core Location Vocabulary

Critical: This is a self-issued attestation (EAA). Verification depends on trust relationship with the issuer. For high-assurance use cases, request additional attestations (EUCC, certifications, etc.).
